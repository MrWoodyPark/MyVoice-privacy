기기 내 녹음과 분석

마이크로 녹음한 음성, 예문, 인식된 문장, 직접 선택한 성별, 주파수·음역·음계 및 인식 일치도를 기기에서 처리합니다. 음성 인식은 지원되는 기기에서 Apple의 기기 내 음성 인식을 사용합니다. 개발자가 운영하는 서버로 녹음이나 인식 문장을 전송하지 않습니다. 앱에는 회원가입, 광고, 행동 분석 SDK가 없습니다.

보관과 삭제

저장하지 않은 녹음은 새 녹음·결과 삭제·화면 종료 시 삭제하며 비정상 종료로 남은 임시 파일은 다음 앱 시작 때 정리합니다. 사용자가 저장한 녹음과 결과는 앱 저장 영역에 보관하며 저장 목록의 삭제 기능으로 지울 수 있습니다. 기기 백업 설정에 따라 운영체제 백업에 포함될 수 있습니다.

사용자가 요청하는 결과 공유

공유 기능은 대표 주파수, 주요 음역, 주요 음계 비율, 예문 인식 일치도만 URL의 # 뒤에 넣습니다. 성별·연구 참고값은 공유 화면에서 포함을 선택했을 때만 담습니다. 녹음 파일, 예문, 인식 문장은 공유하지 않습니다. 링크 복사는 기기 클립보드에 URL을 기록하며 카카오톡·메시지 등은 사용자가 선택한 서비스로 URL을 전달합니다. 각 서비스의 처리에는 해당 서비스의 방침이 적용됩니다.

링크를 가진 사람은 요약을 볼 수 있고 다른 사람에게 다시 전달할 수 있습니다. 링크 자체에 데이터가 있어 회수·만료 기능이 없으며 앱에서 원본을 삭제해도 이미 공유된 링크는 유지됩니다. 공유 내용은 브라우저 기록이나 메시지·클립보드에 남을 수 있습니다.

공유 웹 화면과 외부 서비스

공유 화면과 이 방침은 GitHub Pages에서 제공됩니다. 페이지의 기본 요청 시 GitHub는 IP 주소 등 접속 정보를 처리할 수 있습니다. 결과가 담긴 URL fragment(# 뒤)는 일반적인 HTTP 페이지 요청으로 호스팅 서버에 전송되지 않으며 브라우저에서 해석됩니다. 공유 화면은 분석 결과를 별도 서버에 저장하거나 외부로 전송하는 스크립트, 쿠키, 분석 SDK를 사용하지 않습니다. 메시지 서비스는 사용자가 보낸 전체 링크를 처리할 수 있습니다.
